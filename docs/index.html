Small, sharp skills for AI coding agents.

Drop-in SKILL.md folders that change how an agent works: fewer questions, steadier codebases, clearer goals. Open source, MIT.

autonomy

workflow · per thread

A sticky mode that cuts questions. The agent decides alone, gets a second opinion from a delegate if unsure, and asks you only at hard stops.

Say autonomy on or autonomy off.

ai-durability

setup · audit

Sets up strict typing, boundary checks, synced agent rules and CI gates so a project stays intact while many agents work on it. Audit mode reports drift.

How a skill works

01

One folder

Each skill is a folder with a SKILL.md: a short description and the instructions.

02

Agent matches it

The agent reads the description and loads the skill when your request fits.

03

Behavior changes

The instructions steer the work. Remove the folder and it goes back to normal.

Install

# clone once
git clone https://github.com/jovylle/agent-skills ~/agent-skills

# link the skills you want into your agent's skills folder
ln -s ~/agent-skills/skills/autonomy ~/.agents/skills/autonomy
ln -s ~/agent-skills/skills/ai-durability ~/.agents/skills/ai-durability
ln -s ~/agent-skills/skills/goal-shaping ~/.agents/skills/goal-shaping

# update later
git -C ~/agent-skills pull

The skills folder path depends on your agent. ~/.agents/skills is a common shared location.
